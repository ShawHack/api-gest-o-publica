# Instruções para Adicionar a Logo "Agenda Garça"

## Passo 1: Salvar a Imagem

1. Salve a imagem da logo "Agenda Garça" que você forneceu
2. Renomeie o arquivo para: `logo_agenda_garca.png`
3. Coloque o arquivo na pasta: `assets/`

**Caminho final:** `assets/logo_agenda_garca.png`

## Passo 2: Verificar

Certifique-se de que o arquivo existe em:
```
c:\Users\camilla.lisboa\Documents\prefeitura_app\assets\logo_agenda_garca.png
```

## Passo 3: Executar

Após salvar a imagem, o código já está atualizado para usá-la automaticamente!

```bash
# Mobile
flutter run

# Web
.\run_web.bat
```

## Observação

Se a imagem não aparecer, execute:
```bash
flutter clean
flutter pub get
flutter run
```
