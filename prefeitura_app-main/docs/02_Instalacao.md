# Instalação e Configuração

## Pré-requisitos
- Flutter SDK instalado
- Dart SDK instalado (geralmente incluso no Flutter)
- Conta Firebase configurada

## Passos
1. Clone este repositório
```bash
 git clone <URL>
```
2. Instale as dependências
```bash
 flutter pub get
```
3. Configure o Firebase (adicione `google-services.json` ou `GoogleService-Info.plist` na pasta correta)
4. Execute o projeto
```bash
 flutter run
```
