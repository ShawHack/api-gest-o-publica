# Configuração do Firebase

Este projeto utiliza o Firebase para autenticação, banco de dados e/ou notificações push.

## Passos
1. Criar projeto no [Firebase Console](https://console.firebase.google.com/)
2. Adicionar configuração do Android (`google-services.json`) na pasta `android/app`
3. Adicionar configuração do iOS (`GoogleService-Info.plist`) na pasta `ios/Runner`
4. Configurar `firebase.json` conforme necessário.
