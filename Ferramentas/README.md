# Caixa de Ferramentas do MITI

Plataforma web com grade de ferramentas (PDF + imagens).

## Ferramentas na home (`/`)

- Juntar / Dividir / Comprimir PDF
- PDF ↔ Word, Excel e PowerPoint (via LibreOffice)
- Editar, Assinar, Marca d'água, Rotacionar PDF
- HTML para PDF
- Proteger / Desbloquear PDF
- JPG ↔ PDF e Conversor de Imagens

## Como executar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

**Requisito:** LibreOffice em `C:\Program Files\LibreOffice` para conversões Office/HTML.

```bash
npm run build
npm start
```
